Git & Github

1. Understanding Git and Github

Git is the local software that runs on the users OS whereas gitHUB is exactly as named, a hub for all gits to be centrally located or distributed.

2. VS Source Code Control Process

My current steps for VS source code control is as follows: 1. save all changes to files (stage) 2. navigate to source control panel 3. commit changes by adding a meaningful commit message 4. push to Github 5. verify successful upload and access
